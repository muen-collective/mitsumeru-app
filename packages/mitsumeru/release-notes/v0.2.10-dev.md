# Mitsumeru 0.2.10-dev

Internal build — carries the `-dev` suffix; the update channel is `dev`.

Wraps DeepSeek Harness **0.2.2-rc.1** (from **0.2.1-rc.5**) — the newest release on DSH's `latest`
tag, published 2026-11-04. The first cut on the 0.2.2 line, and the first release to carry
`@muen/dsh-draw`.

## What changed

- **The pin.** 0.2.1-rc.5 → **0.2.2-rc.1**. `0.2.2-rc.2` landed on `next` hours before this cut and
  `0.2.2-alpha.3` on `alpha` a week earlier; `latest` is the channel every re-pin since 0.1.5 has
  followed.

- **`@muen/dsh-draw` ships inside the release.** It landed on `main` on 2026-11-10 in a commit that
  said plainly it was *not* a release (no bump, no notes, no manifest): the vendored plugin, the
  vendor loop's new `assets/` copy, and the `SHIPPED_PLUGINS` row. This cut is the release that
  carries it.

- **The closure grew by a line.** 332 `@deepseek-ai/*` packages resolve (release pins 88) and the
  staged tree is **39,058 files, 0 symlinks** (35,081 at rc.5). 25 names are new — chiefly
  `dsh-action-cards`, `dsh-client-ui-file-actions`, `dsh-client-ui-file-drag`,
  `dsh-client-ui-context-menu`, `dsh-message-quotes`, `dsh-deliverable-file-references`,
  `dsh-creation-recommendations`, `dsh-personalized-recommendations`, `dsh-plugin-detail`, the
  `dsh-experimental-forge*` and `dsh-experimental-liveshare*` sets, and the two tool executors
  (`dsh-tool-executor-native`, `dsh-tool-executor-ptc`). One name is gone:
  `dsh-client-ui-deepseek-model-label-1017`.

- **The beta-badge patch had to be re-derived — the first seam upstream has moved since
  0.2.1-alpha.2.** The Plugins page used to decide the badge with a prefix rule
  (`beta: pkg.name.startsWith("@deepseek-ai/dsh-experimental-")`); at 0.2.2-rc.1 it decides with an
  explicit `new Set([...])` of bundle names and reads `beta: EXPERIMENTAL_BUNDLES.has(pkg.name)`.
  `patches/patch-muen-beta-badge.mjs` failed loudly at the first staging run — its guard refuses to
  edit when the anchor is missing, which is exactly what it is for — and was re-anchored to the new
  predicate, keeping the `|| pkg.name.startsWith("@muen/")` OR clause. The workspace copy at
  `05-dsh-core/patches/` is synced with it; the anchor is the predicate line, not the list, because
  the list grows with every preview bundle upstream ships.

- **The hero-tagline seam applied unchanged** — the same call insertion and factory declaration in
  `dsh-client-ui-conversation`, confirmed by its own `--check` and the slots negative control.

- **The composition patch moved by six rows.** `dsh-web-app/cordis.patch.yml` gains
  `ui-file-actions`, `ui-context-menu`, `message-quotes`, `ui-file-drag` and
  `deliverable-file-references`, loses `ui-deepseek-model-label-1017`, and drops the `tools` row's
  `mode: !!js process.env.DSH_TOOLS_MODE` — upstream retired its own env seam. No new `!!js` gate
  appeared, so nothing of ours vanished behind a profile-name condition.

- **The missing-edge pin still earns its keep.** `dsh-client-ui-renderer@0.2.2-rc.1` still
  `require`s `@deepseek-ai/dsh-client-ui-slots` at module load and still declares it in neither
  `dependencies` nor `peerDependencies`, so the staging pin in `prepare-harness.sh` is unchanged and
  is still what keeps the packaged app from booting to a blank page.

- **Cordis moved a minor: 4.0.5 → 4.1.0** (the renderer's peer range is `~4.1.0` now). No shipped
  `@muen/*` plugin declares a cordis peer, so nothing needed retargeting.

- **The supply-chain age gate needed no edit.** Every 0.2.2-rc.1 package is older than the
  1440-minute cutoff (published 2026-11-04), so `pnpm install` resolved clean. The exception list
  still names 0.2.0-rc.2 packages — leftovers from that re-pin, harmless and left untouched.

## What to check

- The app boots and the conversation renders — the re-pin's only real risk is a surface that loads
  but does not paint.
- **The sidebar still wears our dot** (#FF5E00 / #FF0004), not upstream's.
- **Every `@muen/*` plugin still wears the Experimental badge.** This is the re-derived patch's only
  visible effect, and the one thing a silent miss would hide.
- **The Draw tab opens**, a sketch reaches the agent as element summaries, and the surface survives
  the restart that composes it.
- Upstream's new rows are theirs — file actions, context menu, message quotes, file drag,
  deliverable references. Nothing of ours claims those seats.
- The Plugins page no longer lists upstream's `deepseek-model-label-1017`; nothing of ours used it.

## Windows

Unsigned, as the supported path: the installer carries the win32-x64 payload and its update feed,
and unsigned auto-update works because `app-update.yml` names no publisher. When published it must
use the hyphenated copy (`Mitsumeru-Setup-0.2.10-dev.exe`) that `latest.yml`/`dev.yml` name, the way
0.2.8 and 0.2.9 did — electron-builder writes the file with spaces.
