Internal build — carries the `-dev` suffix; the update channel it belongs to is
`dev`.

**The same app, on a new harness, with sign-in.** This build re-pins DeepSeek
Harness 0.1.7-rc.1 → **0.2.1-alpha.2** (the 0.2.0-rc.2 → alpha.1 → alpha.2
re-pin chain of 2026-09-29…10-09; an alpha pin never ships to the `latest`
channel — 0.2.6 waits for the 0.2.x rc).

**Sign-in is now required.** The first-install gate (founder direction
2026-10-02): a fresh install opens at the sign-in screen — no anonymous use,
the harness does not start until a session exists, and explicit sign-out stops
it and returns to the gate. Sign-in opens the deployed Muen site's sign-in
route in your browser; the `mitsumeru://` callback returns into the app, where
avatar and tier read from the same membership record the site sees. The entry
also registers the `mitsumeru://` protocol pair, so links from the site round
trip back into the app.

**Plugins page shows what you actually have.** The page renders the shipped
Muen bundles (they were invisible before — the profile listed them but the page
filtered them out), the account row shows your account's name, and Settings now
lives in the avatar menu (the old gear rail is hidden; ⌘, still works). Every
`@muen/*` plugin card wears the same **Experimental** badge DSH gives its own
preview plugins — one patched predicate in the plugin-manager client, inside
the app signature, with a build gate so a future harness bump that changes the
line fails the cut instead of shipping unbadged.

**Retired inside the build:** `dsh-turn-summary` and `dsh-codex-fold` left the
shipped set (founder, 2026-10-02). What remains vendored: brand, EVA theme,
white-label, context-watchdog, changes-card.

**Avatar row polish:** light-theme label fixed, no avatar ring.

**The bump's own findings.** The supply-chain age gate holds the harness
closure as an explicit, version-reviewed exception list (289 entries retargeted
to 0.2.1-alpha.2); a re-pin must retarget that list or the build refuses to
run. Every bump is audited against the three upstream breakage classes
(settings/service surface, composition gates, profile bundles).

**Unchanged:** private-plugin gating and pricing are not here — the Muen
plugins installer ships later (0.2.6 line). Windows ships unsigned, so first
run needs one *More info → Run anyway* click.

Wraps DeepSeek Harness 0.2.1-alpha.2 (from 0.1.7-rc.1).

Packaged for all three targets — `Mitsumeru-0.2.5-dev-arm64.dmg` +
`-arm64-mac.zip` (Apple Silicon), `Mitsumeru-0.2.5-dev.dmg` + `-mac.zip`
(Intel) and `Mitsumeru Setup 0.2.5-dev.exe` (Windows x64). Both Mac builds are
notarized and stapled; the feed is the merged `dev-mac.yml`, with `dev.yml`
for Windows.

`Mitsumeru-0.2.5-dev.dmg` (Intel), or `Mitsumeru Setup 0.2.5-dev.exe`

build by the app itself through the update banner.
