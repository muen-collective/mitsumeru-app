# Mitsumeru 0.2.5

Promoted release: no `-dev` suffix, so this takes the `latest` channel. Shipped three targets:
Apple Silicon, Intel and Windows x64.

This is the build that was dogfooded as `0.2.5-dev`, promoted under its own name. The `-dev`
drills (`0.2.4-dev`, `0.2.5-dev`) stay published and keep their own channel, so nothing already
installed is disturbed.

Wraps **DeepSeek Harness 0.2.1-alpha.2**, from 0.1.7-rc.1, which is what 0.2.3 shipped.

## What changed since 0.2.3

**Sign-in is required.** A fresh install opens at the sign-in screen. There is no anonymous use,
the harness does not start until a session exists, and signing out stops it and returns to the
gate. Sign-in opens the Muen site's sign-in route in your browser; the `mitsumeru://` callback
returns into the app, where avatar and tier read the same membership record the site sees. The
entry also registers the `mitsumeru://` protocol pair, so links from the site round trip back
into the app.

**The Plugins page shows what you actually have.** It renders the shipped Muen bundles (they were
invisible before: the profile listed them and the page filtered them out), the account row shows
your account name, and Settings now lives in the avatar menu (the old gear rail is hidden;
Cmd+, still works). Every `@muen/*` plugin card wears the same **Experimental** badge DSH gives its
own preview plugins.

**Retired inside the build:** `dsh-turn-summary` and `dsh-codex-fold` left the shipped set. What
remains vendored is brand, EVA theme, white-label, context-watchdog and changes-card.

**Avatar row polish:** the light-theme label is fixed and the avatar ring is gone.

**The harness re-pin.** 0.1.7-rc.1 to 0.2.1-alpha.2. The supply-chain age gate holds the harness
closure as an explicit, version-reviewed exception list, and a re-pin must retarget it or the build
refuses to run: 289 entries were retargeted here. Every re-pin is audited against the three
upstream breakage classes (settings and service surfaces, composition gates, profile bundles).

## What is not in this build

The Generate, Assets and localisation plugins are **not** here. They are separate packages that
ship from the market: install them in Settings to Plugins by URL. This build is the shell, the
harness and the brand. Private-plugin gating and pricing are also not here; they ship with the
Muen plugins installer in the 0.2.6 line.

## Gates

Run by `pnpm release:cut`, which stops at the first failure and never publishes:

- `PROMOTE=1 check:label` (the `-dev` suffix must be gone from the version and from every artifact)
- `check:identity`, `typecheck`
- build and sign all three targets, then `notarize:all` and `manifest:merge`
- `smoke`, `smoke:native`, `verify:surfaces`, `verify:mount`
- `verify:release`, `verify:artifacts`, `verify:docs`

## Install

| Artifact | Architecture |
|---|---|
| `Mitsumeru-0.2.5-arm64.dmg` / `-arm64-mac.zip` | Apple Silicon |
| `Mitsumeru-0.2.5.dmg` / `-mac.zip` | Intel (x86_64) |
| `Mitsumeru Setup 0.2.5.exe` | Windows x64 |

- **Apple Silicon:** `Mitsumeru-0.2.5-arm64.dmg`
- **Intel:** `Mitsumeru-0.2.5.dmg`
- **Windows:** the `.exe` installer. It is unsigned, so Windows shows SmartScreen: *More info*
  then *Run anyway*.

Both Mac builds are notarized and stapled, so they open on a double-click. `latest-mac.yml` and
`latest.yml` are the update feeds; `latest-mac.yml` is the one a promoted client reads, so a
0.2.3 install is offered this build automatically.
